# Orbit SAT Math

A standalone Next.js prototype for a personalized, adaptive SAT Math learning platform.

## Run locally

```bash
cd /Users/brettskibecker/Documents/Codex/2026-08-17/referenced-chatgpt-conversation-this-is-an
npm install
npm run dev
```

Open `http://localhost:3000`. Content operations are at `http://localhost:3000/studio`, and generator testing is at `http://localhost:3000/quality`.

## Verify the project

```bash
npm run check
```

This validates 2,400 generated questions, review scheduling, interest personalization, mastery scoring, data migrations, every theme asset, TypeScript, and the optimized production build.

## Implemented prototype

- Welcome, create-account, sign-in, Google/Apple provider-ready demos, local continuation, returning-user flow, and three-step personalized onboarding
- Student profile with name, school/location assistance, goals, routine, interests, learning preferences, and context controls
- Adaptive diagnostic with autosave, resume, routed difficulty, skill placement, and comparison on retake
- Lessons, mastery checks, saved progress, search, bookmarks, and real-world connections
- Generated practice with changing values, interest-aware contexts, hints, confidence, elimination, flags, tools, timers, autosave/resume, reports, and answer review
- Two-module simulation with accommodations, timer visibility, review-before-submit, autosave, adaptive Module 2, and full answer review
- Mastery, attempt history, spaced review, plans, local-date streaks, weekly goals, reports, and contextual learning insights
- Theme-aware UI, plain palettes, immersive breakout rooms, appearance overrides, focus mode, responsive navigation, and accessibility settings
- Portable versioned backups with migration and interrupted-session recovery
- Orbit Studio for question templates, lesson drafts, question-report review, publishing, and deterministic previews
